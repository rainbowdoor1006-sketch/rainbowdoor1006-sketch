## 项目

### [RAINBOW MC](https://github.com/rainbowdoor1006-sketch/rainbow-mc) · Minecraft 启动器

给不想折腾的玩家的启动器：不用自己配 Java、不用手动装加载器，整合包拖进去就能玩。

- 版本安装 / 启动，Forge、NeoForge、Fabric、Quilt 一键安装
- 启动前自动补齐缺失的库文件与游戏资源
- 整合包拖入即导入（Modrinth / CurseForge），566 模组 / 1.43 GB 实测 5.1 分钟
- 崩溃判定引擎：读日志给出唯一结论（内存不足、缺前置、驱动崩溃、存档损坏等 29 类）
- 启动前资源预估：按模组数估算内存 / 显存 / CPU，与本机硬件对比
- 房间码联机（内置 Terracotta，P2P，不用开服务器）
- 离线登录
- 覆盖安装与卸载都不删除 `data/`（存档、组件库、游戏文件）

`Electron` `React` `TypeScript` `MIT`
